# Feature guide

## Cards and source links

Cards can hold ideas, Zotero references, notes, annotations, canvas embeds, diagrams, images and documents. Linked notes use Zotero's native editor; annotation cards retain their quote/comment and highlight colour. Open source jumps to the saved annotation in the reader when the original is available. Deleting a card does not delete its Zotero source.

## Canvas structure

Use freeform or mind-map mode. Frames can be named and coloured separately from cards, moved with their enclosed cards, resized, and used as export regions. The Canvas Explorer supports folders, drag-and-drop organisation, nested canvas links, Trash and recovery. Multiple selection supports group movement and alignment. Use the bottom-left toolbar for zooming and fit-all.

## Connectors and link types

Connectors can be curved, straight or elbow shaped, with free endpoints and draggable bend points. Select an endpoint to reconnect it, or drag a card port into empty space for a loose connector. Edit labels directly on the line; labels wrap to remain visible. Settings provide reusable link types with a label, colour, line pattern, thickness, route and arrows. A connector between two linked Zotero notes can also create their reciprocal Related relationship; deleting the canvas connector leaves that Zotero relationship in place.

## Objects and libraries

The left toolbar offers basic shapes, six sticky colours, text boxes, editable grid tables, wireframe elements and research templates. The Object library includes 26 Forms vectors from Excalidraw Libraries; import version 1/2 `.excalidrawlib` files for more vector composites. Unsupported images or shapes in a library are reported. Embedded files are copied into the canvas JSON, with a 20 MB per-file limit; image and document previews are scrollable as appropriate.

## Search and AI

Keyword search includes Zotero titles, notes, tags and annotations. Search type filters restrict results to Notes, Annotations or References. Semantic search needs the optional Zotero MCP Plugin index. The card AI menu has Connections, Counter and Supporting. Each result shows an explanation and excerpts; users choose which ones to add. Suggested AI interpretations are saved with accepted cards and connectors for later review.

## Export and recovery

Export editable JSON; create static SVG, PNG or PDF of the full canvas or a selected frame; send an editable snapshot to Obsidian Canvas. Obsidian exports preserve linked-source notes and embedded assets but use Obsidian's own typography and connector rendering. Automatic local version snapshots support restoring earlier arrangements. Canvas files are local; simultaneous editing of one board file by multiple processes is not supported.
